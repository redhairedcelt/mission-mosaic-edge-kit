# Content boundary

This participant kit contains encrypted evidence releases and enduring
participant-safe references. It does not contain:

- release words;
- facilitator guides, routes, credentials, or timing controls;
- ground truth, hidden intent, adjudication, answer keys, or scoring logic;
- master event sequences, inject controls, or exercise-control notes;
- intended conclusions or completed answer products;
- the Mission Mosaic event host, API keys, connector tokens, or access logs.

H120 contains the completed participant-safe analytical corpus, not protected
facilitator ground truth. The package builder rejects protected path names and
the release manifests assert that facilitator paths are excluded.
